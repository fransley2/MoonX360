# Included Wallpaper

`home-wallpaper.png` is the 1280x720 PNG supplied by the MoonX360 maintainer for the v0.2.4 release. The package preserves the supplied bytes.

Install it through MoonX360's **Choose wallpaper** browser, or copy it to the installation's `moonlight/home-wallpaper.png` and select **Custom wallpaper**. Existing settings and pairing files should be preserved.
