# Contributing

Keep changes focused and preserve copyright and license notices. Describe behavior changes and include the [dashboard build](docs/BUILD.md) result when relevant. Identify which checks ran on the host and which ran on a physical Xbox 360.

Report issues with the MoonX360 version, host software, stream settings, and steps to reproduce. Remove pairing material, host addresses, local paths, and other private data from shared logs. Keep SDK files and generated builds out of Git.
