# Contributing

Keep changes focused and preserve upstream and dependency copyright notices. Describe behavior changes and run the relevant host checks from [BUILD.md](docs/BUILD.md). State separately whether you compiled an XEX and whether you tested on a physical Xbox 360.

Performance reports should identify the source/build policy, console/display mode, server and encoder, content, network, requested settings and measured received/decoded/presented rates. Do not infer stable playback from build success or a single synthetic fixture.

Never attach pairing keys, client certificates, CPU keys, PINs, personal host lists or unredacted diagnostics. Do not commit XDK/SDK components or build artifacts. Retain the runtime storage namespace for existing users; public branding is not a reason to break stored identities or settings.
