# Xbox 360 dashboard target

See [Build MoonX360](../docs/BUILD.md) for SDK requirements, vendored dependencies, and commands to build **default.xex**.

- **src/** and **compat/** contain the dashboard platform layer.
- **ffmpeg_xbox/** contains Xbox-specific decoder adaptations.
- **build.py** builds the application and packages the dashboard resource.
- **aurora/** contains the Aurora integration scripts copied by the build.

See [Aurora shortcuts](../docs/AURORA_DIRECT_LAUNCH.md) for the optional launcher.
